# Palimpsest — 專案總覽

## 1. 專案願景

打造一個類似「起點中文網」的全平台小說閱讀應用程式，支援中英文小說閱讀、即時繁簡翻譯與英文翻譯功能，提供流暢的離線閱讀體驗。

## 2. 專案目標

| 目標 | 描述 |
|------|------|
| **跨平台覆蓋** | Web、Android、iOS、Windows、macOS、Linux |
| **多語言閱讀** | 支援繁體中文、簡體中文、英文小說 |
| **即時翻譯** | 繁簡互轉 + Google Translate API 英文翻譯 |
| **離線體驗** | 本地 SQLite 緩存，無網路也能閱讀 |
| **社群互動** | 書評、章節留言、評分、排行榜 |

## 3. 專案範圍

### 3.1 範圍內（In Scope）

- 會員系統（註冊、登入、個人資料管理）
- 書城（瀏覽、分類、搜尋、排行榜）
- 閱讀器（捲動模式、翻頁模式、閱讀設定）
- 書架管理（收藏、分組、閱讀進度同步）
- 翻譯系統（繁簡轉換、Google Translate 英文翻譯）
- 離線功能（章節下載、本地 SQLite 緩存）
- 社群功能（書評、留言、評分）
- 管理後台（小說管理、用戶管理、內容審核）

### 3.2 範圍外（Out of Scope — 未來考慮）

- 付費/訂閱系統
- 作者投稿平台
- 即時通訊/私訊
- AI 推薦系統（Phase 3 才考慮）

## 4. 目標用戶

| 角色 | 描述 |
|------|------|
| **讀者** | 閱讀小說的主要用戶，需要流暢的閱讀體驗和離線功能 |
| **管理員** | 管理小說內容、審核用戶評論、維護平台秩序 |
| **超級管理員** | 系統級設定、用戶權限管理 |

## 5. 核心用戶故事

1. 作為讀者，我可以**瀏覽書城**找到感興趣的小說
2. 作為讀者，我可以**搜尋**小說名稱或作者
3. 作為讀者，我可以**閱讀章節**並自訂閱讀介面
4. 作為讀者，我可以**將小說加入書架**並在多裝置同步進度
5. 作為讀者，我可以**下載章節離線閱讀**
6. 作為讀者，我可以**翻譯**簡體內容為繁體，或將中文翻譯為英文
7. 作為讀者，我可以**撰寫書評和留言**與其他讀者互動
8. 作為管理員，我可以**管理小說內容**和審核用戶評論

## 6. 技術棧摘要

| 層級 | 技術 |
|------|------|
| **後端** | Go (Gin) + PostgreSQL + Redis + Meilisearch |
| **Web 前端** | Nuxt 3 + Vue 3 + TypeScript + Pinia |
| **Mobile/Desktop** | Flutter + Riverpod + sqflite |
| **物件儲存** | MinIO (S3 相容) |
| **翻譯** | OpenCC（繁簡）+ Google Translate API（英文）|
| **部署** | Docker + Kubernetes |

## 7. 開發優先順序

```
第一階段（MVP）：Web App + Android App
第二階段：iOS App + 功能擴展
第三階段：Desktop App（Windows / macOS / Linux）
第四階段：商業化功能
```

## 8. 關鍵績效指標（KPI）

| 指標 | MVP 目標 |
|------|----------|
| API 回應時間（P95） | < 200ms |
| 閱讀頁面載入時間 | < 1.5s |
| 離線閱讀可用率 | 100%（已下載章節）|
| 翻譯回應時間 | < 3s（Google Translate）|
| Lighthouse 分數 | > 90（Web）|
| Crash-free Rate | > 99.5%（Android）|

## 9. 風險評估

| 風險 | 影響程度 | 機率 | 緩解措施 |
|------|----------|------|----------|
| Google Translate API 費用超支 | 高 | 中 | 翻譯結果緩存 + 每日額度限制 |
| Flutter 閱讀器效能不佳 | 中 | 低 | 提前做效能驗證 POC |
| 跨平台 SQLite 行為差異 | 中 | 低 | 統一 Migration + 完整測試 |
| 內容版權問題 | 高 | 中 | 初期使用公版/授權內容 |
